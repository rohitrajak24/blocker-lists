# Notice: list sources

The compiled lists combine data from these projects. Many thanks to their maintainers.

| Source | Data | License |
|---|---|---|
| [oisd](https://oisd.nl) (nsfw) | Adult domains | GPL-3.0 |
| [HaGeZi DNS blocklists](https://github.com/hagezi/dns-blocklists) (nsfw, gambling, doh) | Adult, gambling and encrypted-DNS domains | GPL-3.0 |
| [StevenBlack/hosts](https://github.com/StevenBlack/hosts) (porn-only, gambling-only) | Adult and gambling domains | MIT |
| [Google supported domains](https://www.google.com/supported_domains) | Google search domains for SafeSearch mapping | Public list |

The data is merged, normalized and de-duplicated. Subdomains already covered by a listed parent
domain are removed. Each release's notes list the exact entry counts per source.
